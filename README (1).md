# Netflix Content Analysis Dashboard \| Power BI

## Project Overview

This project presents an interactive Netflix content dashboard built in
Microsoft Power BI. It summarizes the available Netflix titles and helps
explore movies, TV shows, genres, release years, runtime, IMDb scores,
and country-level subscriber information.

## Dashboard Features

-   **KPI cards:** Runtime hours, movie count, TV show count, and
    average IMDb score
-   **Top 5 genres:** Comparison of the most common genres
-   **Content by year:** Trend of movies and TV shows over time
-   **Movies vs. TV shows:** Share of each content type
-   **Country map:** Geographic view included in the report
-   **Interactive filters:** Filter by title, genre, and year

## How to Open the Project

1.  Download or clone this repository.
2.  Open the `.pbix` report file in Power BI Desktop.
3.  If prompted, update the data source path to point to the dataset on
    your computer.
4.  Refresh the data if needed.
